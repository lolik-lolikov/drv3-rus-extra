# Шрифты

Все шрифты в папках `fonts`, `fonts2`, `fonts3`, `fontdl` — свободные, взяты из Google Fonts / fontsource
и распространяются по своим лицензиям:

| Шрифт | Лицензия |
|---|---|
| Amatic SC, Comfortaa, Days One, Exo 2, Great Vibes, Kelly Slab, M PLUS Rounded 1c, Marck Script, Montserrat Alternates, Neucha, Oswald, Philosopher, Press Start 2P, PT Sans, PT Sans Narrow, PT Serif, Roboto, Rubik, Rubik Mono One, Russo One, Seymour One | SIL Open Font License 1.1 |
| Ubuntu | Ubuntu Font Licence 1.0 |

Оригинальный шрифт игры (FOT-Humming Std D) в репозиторий не входит: инструмент `tools/build_v3font.py`
берёт его из вашей копии игры.
